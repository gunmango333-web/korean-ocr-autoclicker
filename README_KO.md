# 한글 인식 오토클리커 (초안)

## 동작
- 화면의 한글 `약`, `중`, `강`을 OCR로 찾습니다.
- 대응하는 한자 `弱`, `中`, `強`가 화면에 인식될 때만 해당 한자 위치를 클릭합니다.
- 한글이 화면에 계속 떠 있는 동안에는 한 번만 클릭합니다.
- 한글이 사라졌다가 다시 나타나면 다시 클릭할 수 있습니다.
- 트리거 한글이 없거나 대응 한자를 찾지 못하면 클릭하지 않습니다.

## 중요
이 프로젝트는 소스/빌드 초안입니다. 현재 상태에서 OCR 언어 데이터와 Tesseract 실행 파일을 포함한 완성 EXE가 자동으로 제공되는 것은 아닙니다. 배포용 빌드에는 Tesseract OCR 엔진 및 `kor`, `chi_sim` 언어 데이터가 필요합니다. 한자 `中`은 여러 상황에서 흔한 글자라 엉뚱한 곳을 찾을 수 있으므로, 실제 화면에서 충분히 테스트하세요.

## 개발 환경에서 실행
1. Windows에 Python 3.11을 설치합니다.
2. Tesseract OCR을 설치하고 `kor`, `chi_sim` 언어 데이터를 추가합니다.
3. 터미널에서 프로젝트 폴더로 이동해 `pip install -r requirements.txt`를 실행합니다.
4. `python autoclicker.py`로 실행합니다.

## 설치 없는 EXE로 만들기
PyInstaller만으로 Tesseract 엔진과 언어 데이터를 자동 포함하지 않습니다. 배포하려면 Tesseract 폴더(실행 파일 및 `tessdata`의 `kor.traineddata`, `chi_sim.traineddata` 등)를 함께 묶어야 합니다. 이를 포함하지 않은 EXE는 다른 PC에서 OCR 엔진 오류가 날 수 있습니다.
